Quantum Machine Learning (QBM Module)

Scientific Requirement & Implementation Distinction

This module implements a Quantum-Inspired Variational Boltzmann Machine (QBM) using PennyLane and Qiskit Aer simulation. The application explicitly distinguishes between classical ML, quantum simulation, and physical quantum hardware. It runs completely offline on standard CPU hardware without requiring IBM Quantum cloud credentials.
